The grammar turns knowledge-graph extraction into multiple choice

Graphiti pays a language model to read each message and write out its entities and facts. The kernel's grammar does that reading on your own machine and writes the options, so the decisions left over can go to a model that only picks between them.

Extraction and deduplication were almost all of Graphiti's bill on this conversation. They cost the kernel nothing.

Across a full ten-conversation benchmark that comes to about half the cost: $2.36 for the kernel, against $4.82 for Mem0 and $5.49 for Graphiti as measured by KTH.

How these were measured
  • Both builds read the same 24 messages and embed with voyage-3. Graphiti is graphiti-core 0.31.2 with default ingestion, in its json_object mode through OpenRouter.
  • Graphiti's bill depends on the model you give it: the same tokens would cost about $0.027 on gpt-4o-mini. It can't run on jev-1.13, which only picks between options.
  • This conversation is too short to show Graphiti's summary costs. It appends new facts to an entity's summary for free, then pays the model to rewrite it past 2,000 characters. That was 2 of its 86 calls here, and busy entities trigger it more often as a graph grows.
  • This is a full build, which settles duplicates from the parse. Appending later can ask the picking model a yes or no on a hard case.
  • Neither bill counts compute. The kernel's parsing runs on your own hardware.
  • On that benchmark, Mem0 and Graphiti are OpenAI spend on gpt-4o-mini. The kernel's $2.36 is calculated: it adds up the build stages this version keeps from our last full run.
